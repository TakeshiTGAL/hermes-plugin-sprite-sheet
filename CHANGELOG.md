# Changelog

## 0.1.2

A later process with no person and no gateway no longer writes the game project after always. The plugin refuses that turn itself. An interactive CLI is recognized when the turn binds `hermes_interactive`, not only when the process environment has `HERMES_INTERACTIVE`. A plan that deletes a file asks on every call, so always does not cover the next call. The approval line keeps the deleted file's name when the path list is long.

## 0.1.1

A saved always line no longer writes the game project from cron, `hermes -q`, webhook, or the plugin host. The same plan still applies only when a person is present. `inspect_grid` and `write` false stay silent. A bad argument returns `error_type` `invalid_argument`. `platforms` is `macos`. The skill file is `skills/cut-sprite-sheet/SKILL.md`.
